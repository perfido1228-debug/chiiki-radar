# 情報源の探し方（Claude 向け）

本番の地域密着レーダー（1都3県・愛知・大阪・京都で約350の情報源）を作ったときの学びをまとめたもの。

## どんなサイトが役に立つか（効き目の順）
1. **地域の開店・閉店ブログ（個人運営）** … 「〇〇市の開店閉店情報」のようなブログ。開店記事が多く、店名・場所がはっきり書かれる。いちばん効く。名鑑に載っていないので Web 検索で探す。
2. **号外NET（地域版）** … 全国にあり、開店・閉店の記事が多い。地域版ごとに書き手がいなくなって長く止まることがある（親サイトは動いていても、その地域版は止まっている）。最新の記事の日付を必ず見る。
3. **みんなの経済新聞（〇〇経済新聞）** … 開店記事が丁寧で住所が正確。本数は少なめ。
4. **メシナビ** … 飲食店の開店専門（全国）。対象の地域の記事だけが取り込まれる。
5. **リビングWeb「開店・閉店」**（首都圏・関西など）、**居抜き店舗.com**（1都3県）… 専用の読み方で読む。
6. 地域のポータル・タウン誌のWeb版 … サイトによる。イベントや行政の話ばかりなら入れない。

入れないもの: 止まっているサイト／開店の記事がほとんど無いサイト／全国のグルメまとめ（地域がばらばら）／フィードが無いサイト。

## フィード（RSS）の見つけ方
- ページの `<head>` にある `<link rel="alternate" type="application/rss+xml" href="…">`
- WordPress: `https://サイト/feed/`（過去の記事も `?paged=2` で遡れるので相性がよい）
- livedoor ブログ: `https://サイト/index.rdf`　Seesaa: `https://サイト/index.rdf`
- はてなブログ: `https://サイト/rss`　note: `https://note.com/{ID}/rss`
- アメブロ: `https://rssblog.ameba.jp/{ID}/rss20.xml`
- FC2: `https://サイト/?xml`

## 試し読みで見るところ
`node tools/check-source.mjs --feed <URL> --pref <都道府県> [--city <市区町村>] --name <名前>`
- `[取込候補]` … 店として取り込まれるもの。店名・市区町村・ジャンル・オープン日が合っているか。
- 件数が0、または見出しの開店記事が拾えていない → `--show-rejected` で落ちた理由を見る。
- 店名がおかしい（地名や「〇〇に新店」まで含む）ものが少しなら問題ない。大半がおかしければ入れない。

## 読み方の調整（rules）
サイトによって書き方の癖がある。`--rules '<JSON>'` で試し読みし、良ければ同じものを `sources.mjs add --rules` で登録する。

| 名前 | 使うとき | 例 |
|---|---|---|
| `categoriesAsText` | 本文に業種が書かれず、記事の分類（カテゴリ）にだけ「カフェ」等が付く | `{"categoriesAsText":true}` |
| `openingInBody` | 見出しに「オープン」と書かないサイト。本文がこの形なら開店記事として読む（正規表現の文字列） | `{"openingInBody":"の新店「"}` |
| `genreWord` | 業種を書かない専門ブログ（ラーメン専門など）で、業種を補う | `{"genreWord":"ラーメン"}` |
| `pageCategoryLinks` | 記事ページの分類リンクに市区町村が書かれている（そこから場所を取る。CSSセレクタ） | `{"pageCategoryLinks":"a[href*=\"/category/\"]"}` |
| `contentSelector` / `dropSelector` | 本文が一般的な場所に無い／本文の中に関連記事などの別の店の話が混ざる（CSSセレクタ） | `{"contentSelector":"#single","dropSelector":".related"}` |

PowerShell では JSON の `"` が崩れることがある。うまくいかないときは `--rules` を付けずに登録し、`config/sources.json` のその行に `"rules": {...}` を直接書く。

## 場所（市区町村）の決まり方
1. 記事の本文の住所（「〇〇市〇〇町1-2-3」）
2. 見出し・本文に出てくる市区町村名
3. 情報源に `--city` を付けていれば、その市区町村
4. どれも無ければ、都道府県だけの店になる（市区町村の絞り込みでは出ない）

担当の地域がはっきりしたブログ（「〇〇市の開店情報」）には `--city` を付ける。号外NETの地域版も地域がはっきりしているので付ける（候補一覧から入れれば自動で付く）。
