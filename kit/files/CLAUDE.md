# 地域密着レーダー（PC版）— Claude 向けの設定手順

このフォルダは「地域密着レーダー」のPC版キットです。地域の情報サイト（地域メディア・個人ブログなど）を巡回して、
**飲食店の新規開店**の情報を集め、ブラウザで一覧にします（デリバリー導入の営業先さがしに使う）。
データはこのPCの中（`data/`）だけに保存され、費用はかかりません。

ユーザーから「このキットを設定して」「地域密着レーダーを設定して」と頼まれたら、下の手順で進めてください。

## 守ること
- ユーザーへの説明・質問・報告は**日本語で、専門用語を避けて短く**。
- 有料のサービス（API など）は使わない。どうしても必要なら、**先に費用を伝えて**了承をもらう。
- ソフトを入れる（Node.js など）ときは、先にユーザーに聞く。
- 頼まれていないことはしない。直したほうがよいことに気づいたら、先に提案して決めてもらう。
- `app/` `ui/` `masters/` の中は書き換えない（キットを入れ替えると消える。本番のしくみをまとめたもの）。

## フォルダの中身
| 場所 | 中身 |
|---|---|
| `起動.bat` / `起動.command` | 画面を開く。この窓を開いている間、1時間ごとに自動で巡回する |
| `今すぐ巡回.bat` / `今すぐ巡回.command` | 手で1回だけ巡回する |
| `config/area.json` | 対象の地域（`tools/area.mjs` で作る） |
| `config/sources.json` | 情報源の一覧（`tools/sources.mjs` で足す・止める） |
| `data/` | 集めたデータ（stores.json＝店／articles.json＝記事／crawl.log＝巡回の記録） |
| `tools/` | 設定に使う道具（下で説明） |
| `work/` | 候補さがしの結果（`work/candidates.md`） |
| `docs/情報源の探し方.md` | 情報源を選ぶ基準・サイトごとの読み方の調整・これまでの学び（**手順3の前に読む**） |
| `app/` `ui/` `masters/` | プログラム本体・画面・全国の市区町村などの一覧（さわらない） |

コマンドはすべて**このフォルダで**実行する（例: `node tools/area.mjs show`）。

## 1. 動く準備
1. `node -v` で Node.js（20 以上）があるか確かめる。無ければ「無料の Node.js を入れてよいか」聞いてから入れる。
   - Windows: `winget install OpenJS.NodeJS.LTS`（入れた後は新しいターミナルで `node -v`）
   - Mac: Homebrew があれば `brew install node`。無ければ https://nodejs.org の LTS（.pkg）をユーザーに入れてもらう。
2. **Mac のとき**は、ダブルクリックで動くように一度だけ実行する:
   `chmod +x *.command && xattr -dr com.apple.quarantine .`

## 2. 地域を決める
ユーザーに「見たいのは、どの都道府県の、どの市区町村か」を聞く（複数可。市区町村を決めなければ都道府県の全体）。
- 市区町村名の確認: `node tools/area.mjs cities 北海道`
- 保存: `node tools/area.mjs set --name 札幌 --area 北海道:札幌市,江別市`
  - 都道府県が複数なら `--area` を並べる（例: `--area 北海道:札幌市 --area 宮城県:仙台市`）。
  - 政令市は「札幌市」で全区、「札幌市中央区」でその区だけ。
  - **選んだ市区町村の店だけが一覧に出る**（巡回は都道府県全体の記事を読み、表示で絞る）。
- 確認: `node tools/area.mjs show`

## 3. 情報源を探して登録する（いちばん大事）
先に `docs/情報源の探し方.md` を読むこと。

### 3-1. 自動で候補を集める
`node tools/find-sources.mjs`（数分かかる）→ `work/candidates.md` を読む。候補には番号（c1, c2…）が付く。
- **確認済み（本番で使用中）** … 1都3県・愛知・大阪・京都なら、本番の地域密着レーダーで選び抜いた情報源がそのまま出る。基本は全部入れてよい。
- **号外NET／みんなの経済新聞／リビングWeb** … 「更新中」なら入れてよい。号外NETは地域版ごとに書き手がいなくなって止まることがある（最新が古いものは入れない）。
- **地域メディア名鑑** … 中身（最近の見出し）を見て、3-3 の基準で判断する。
- **メシナビ**（飲食店の開店専門・全国）… 入れてよい。対象の地域の記事だけが取り込まれる。
- **居抜き店舗.com**（1都3県のみ候補に出る）… 入れてよい。

### 3-2. 名鑑に無いサイトをWeb検索で探す
個人の開店ブログは名鑑に載っていないことが多く、営業先さがしには一番役に立つ。市区町村ごとに検索する。
- 例: 「{市区町村} 開店 閉店 ブログ」「{市区町村} 新店 オープン 情報」「{駅名} 開店情報」「{市区町村} ニューオープン グルメ」「{市区町村} 開店閉店 まとめ」
- 見つけたらフィード（RSS）を探す: ページの `<link rel="alternate" type="application/rss+xml">`、WordPress は `/feed/`、livedoor・Seesaa は `/index.rdf`、はてなは `/rss`、アメブロは `https://rssblog.ameba.jp/{ID}/rss20.xml`。

### 3-3. 入れてよいかの基準
- 直近1か月に記事がある（止まっているサイトは入れない）。
- 飲食店の開店の記事が**月に数件以上**ある（イベント・行政・生活情報が中心で、開店記事がほぼ無いサイトは入れない）。
- 対象の地域の記事が中心。
- フィード（RSS）がある。**フィードが無いサイトは今のしくみでは読めない**（リビングWeb と 居抜き店舗.com だけは専用の読み方がある）。

### 3-4. 試し読みしてから登録する
- 試し読み（登録はしない）:
  - `node tools/check-source.mjs --candidate c3`
  - `node tools/check-source.mjs --feed <フィードURL> --pref 北海道 --city 札幌市 --name <名前>`
  - `[取込候補]` の店名・市区町村・ジャンル・オープン日が正しいか見る。`--show-rejected` を付けると「開店記事ではない」と判断した見出しも理由つきで出る（取りこぼしの確認）。
  - 店名に地名が付く・場所が決まらない・業種が読めない、などは `docs/情報源の探し方.md` の「読み方の調整」を試す（`--rules '{"categoriesAsText":true}'` のように渡せる）。
- 登録:
  - 候補から: `node tools/sources.mjs add-candidates c1,c3,c5`
  - 自分で: `node tools/sources.mjs add --name <名前> --feed <URL> --pref <都道府県> [--city <市区町村>] [--type 号外NET|経済新聞|独立系ブログ] [--rules '<JSON>']`
  - 担当の市区町村がはっきりしているサイトは `--city` を付ける（記事に住所が無いときの場所になる）。広い地域を扱うサイトには付けない。
- 一覧: `node tools/sources.mjs list`　止める: `node tools/sources.mjs disable <番号>`　消す: `remove <番号>`

## 4. 初回の取り込み
`node app/crawl.mjs --max-pages=30`
- 新しく足した情報源は、過去120日分まで遡って取り込む（数分かかる）。最後に「新しい店: N 件」と出る。
- 取得失敗が多い・0件のときは、情報源を見直す（手順3）。

## 5. 画面を開いて確かめる
`起動.bat`（Mac は `起動.command`）をダブルクリック → ブラウザで http://localhost:4517 が開く。
- 店が出るか、市区町村の絞り込み、右上の「情報源の状況」「今すぐ巡回」を確かめる。
- ユーザーに伝える: 「黒い窓（Mac はターミナル）を開いている間、1時間ごとに自動で集めます。閉じると止まります」

## 6. （希望があれば）PCの起動と一緒に動かす
- Windows: スタートアップ フォルダ（エクスプローラーのアドレス欄に `shell:startup`）に `起動.bat` のショートカットを置く。
- Mac: システム設定 → 一般 → ログイン項目 に `起動.command` を足す。

## 7. ユーザーへの報告
次を短く伝える: 地域／登録した情報源の数（種類ごと）／初回に取り込んだ店の数／画面の開き方（起動.bat）／費用はかからないこと。

## あとから頼まれやすいこと
- 地域を変える・足す → 手順2 → 3 → 4
- 情報源を足す・止める → 手順3（足した分は次の巡回で120日前まで遡る）
- 集まる店が少ない → 画面右上「情報源の状況」で止まっているものを止め、手順3で探し直す
- 他の人にも見せたい（Web版にしたい） → このキットは本番の Web 版と同じデータの形。キットを作った人に相談するよう伝える

## 困ったとき
- 画面が開かない → `起動.bat` の窓のメッセージを見る（Node.js が無い／すでに起動している＝ブラウザで http://localhost:4517 を開く）
- 巡回の記録 → `data/crawl.log`（失敗した情報源と理由が出る）
- 「別の巡回が動いているので、今回は見送ります」 → 前の巡回が終わるのを待つ（止まったままでも3時間で解除）
- 店名・住所・ジャンルの読み方そのもの（読み取りルール）はキットでは直せない。おかしな読み方が多いサイトは止める。
